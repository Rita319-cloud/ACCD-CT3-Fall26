Mouse-driven inflating type, recreated in p5.js

About

At the beginning, I wanted to work on a physical computing project: using components like sliders to control the size, position, and interrelationships of on-screen content (FC Variable by robenrobin.nl).

However, as I explored the projects in my collection folder, I decided to focus on something I haven’t done before. Many thanks to Maxim for recommending Schultzschultz, their typography projects are fascinating.

Among the many amazing projects, I chose a typeface design that deforms based on the mouse's position. As the mouse moves, the slender characters expand and contract. Hovering the mouse causes the letters to inflate like balloons, while moving it away allows them to shrink back to their original shape. This real-time interaction looks incredibly cool.

After selecting my reference, I worked backward from the result to figure out the implementation method. I knew it could be done using p5.js, but I wasn't sure of the specific steps.

Kluding

Here is the process I followed to recreate the Schultzschultz project with the help of AI:

  1. Uploaded the video for the AI to analyze the technique and generate the code.

  2. Copied the code to preview the result; the output was very close to the original.

  3. The font was too thin, so I needed to make it bolder. Also, the letters were being obscured by the slider when the window was resized, so the webpage needed to be responsive.

  4. Asked the AI to make adjustments based on this feedback, resulting in an excellent outcome. Expanded the project from a single letter "R" to the full 26-letter alphabet.

  5. Had the AI annotate the code and explaining the underlying implementation principles.
